🔬 Debug Lane Detection

Sends the current frame to the detector and shows lane polygons + vehicle assignments overlaid. Use this to verify and calibrate lane_config.json.

🟢 Green = SA→LS  |  🔴 Red = LS→SA  |  🟡 Yellow = Unassigned  |  🟠 Orange = Parked

🚗 Follow a Vehicle

Shows the vehicles the per-view tracker is currently watching. Pick one and the panel below polls every 3 seconds to show its live progress — direction, time tracked, current speed — until it exits (or the tracker loses it). Reads the most recent cached burst for the view you choose; the background loop refreshes each angle as the HLS stream rotates to it (every few minutes).

Click a vehicle in the image (or in the list) to start following it:
